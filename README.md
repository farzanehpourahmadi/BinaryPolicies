# Prescriptive Learning of Linear Policies for Binary Decision-Making

## Contents
- `unit_commitment/` – notebook for the unit commitment case study 
- `staff_allocation/` – notebook for the staff allocation case study 

Each notebook trains three models (classical predictive, prescriptive, distributionally
robust prescriptive), evaluates them on a close and a far test set, and reproduces the
figures in the paper.

## Requirements
- Python 3.10+
- numpy, pandas, scipy, matplotlib
- Gurobi (gurobipy) with a valid licence (academic licences are free)

## Usage
Open the notebook and run all cells.
